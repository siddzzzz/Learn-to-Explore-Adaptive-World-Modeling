# Mathematical Formulation: End-to-End Neural Causal World Models

**Target**: NeurIPS / ICML Theoretical Addendum  
**Topic**: Differentiable Graph Induction & Active Markov Equivalence Disambiguation  

---

## 1. Problem Formulation: Beyond Discrete Rule Menus

In classical Bayesian hypothesis testing, candidate mechanisms are selected from a predefined discrete set $\Theta = \{\theta_1, \dots, \theta_K\}$. However, in unstructured, open-ended environments, the agent must construct its own structural hypotheses from scratch.

We formalize this as learning a **Differentiable Structural Causal Model (Neural SCM)** parameterized by:
1. A continuous variational posterior over Directed Acyclic Graphs (DAGs): $q_\psi(G)$.
2. A set of modular neural mechanism networks: $\mathcal{F}_\phi = \{f_{\phi_1}, \dots, f_{\phi_d}\}$.

$$\mathcal{M}_{\text{causal}} = \langle q_\psi(G), \mathcal{F}_\phi \rangle$$

---

## 2. Differentiable DAG Parameterization & Acyclicity

Let $A \in \{0, 1\}^{d \times d}$ be the binary adjacency matrix of causal variables $X \in \mathbb{R}^d$, where $A_{ij} = 1$ denotes a directed edge $X_i \to X_j$.

### 2.1 The NOTEARS Acyclicity Constraint (Zheng et al., 2018)
A continuous directed graph represented by a weighted adjacency matrix $W \in \mathbb{R}^{d \times d}$ is a **Directed Acyclic Graph (DAG)** if and only if:

$$h(W) \triangleq \text{Tr}\left( \exp(W \circ W) \right) - d = 0$$

where:
- $\circ$ denotes the Hadamard (element-wise) product: $(W \circ W)_{ij} = W_{ij}^2$.
- $\exp(\cdot)$ denotes the matrix exponential: $\exp(M) = \sum_{k=0}^\infty \frac{M^k}{k!}$.
- $\text{Tr}(\cdot)$ is the matrix trace.

#### Gradient of the Acyclicity Constraint:
$$\nabla_W h(W) = 2 \left( \exp(W \circ W) \right)^\top \circ W$$

## 3. Variational Graph Posterior via Gumbel-Softmax

To enable gradient-based learning through discrete graph structures, we parameterize edge probabilities using variational logits $\Psi \in \mathbb{R}^{d \times d}$ (with $\Psi_{ii} = -\infty$):

$$q_\psi(A_{ij} = 1) = \sigma(\Psi_{ij}) = \frac{1}{1 + \exp(-\Psi_{ij})}$$

### 3.1 Differentiable Continuous Relaxation (Concrete / Gumbel-Softmax)
During the forward pass, soft adjacency samples $\tilde{A} \in [0, 1]^{d \times d}$ are generated using independent Gumbel perturbations $g_0, g_1 \sim \text{Gumbel}(0, 1)$:

$$\tilde{A}_{ij} = \sigma\left( \frac{\Psi_{ij} + g_{1, ij} - g_{0, ij}}{\tau} \right)$$

where $\tau > 0$ is the annealing temperature. As $\tau \to 0$, $\tilde{A}$ converges to exact discrete binary samples.

---

## 4. Modular Neural Mechanism with Pearl's Intervention Masking

Each causal variable $X_i$ is generated by an independent neural mechanism $f_{\phi_i}$:

$$X_i = f_{\phi_i}\left( \tilde{A}_{:, i} \odot X, a \right) + \epsilon_i, \quad \epsilon_i \sim \mathcal{N}(0, \sigma_i^2)$$

### 4.1 Pearl's Interventional Mutilation ($\text{do}$-calculus)
When the agent executes an active intervention $\text{do}(X_k = v_k)$:
1. The incoming causal parents into $X_k$ are completely severed:
   $$\tilde{A}_{:, k}^{\text{mutilated}} = \mathbf{0}$$
2. The mechanism $f_{\phi_k}$ is replaced by the forced value $v_k$:
   $$X_k = v_k$$
3. Downstream variables $j \neq k$ continue to compute $X_j = f_{\phi_j}(\tilde{A}_{:, j} \odot X, a)$.

---

## 5. Active Causal Discovery: Breaking Markov Equivalence

### 5.1 The Observational Ambiguity Theorem
**Theorem (Verma & Pearl, 1990)**:
Observational data can only identify a causal graph up to its **Markov Equivalence Class (MEC)**. Multiple distinct DAGs (e.g., $X \to Y \to Z$, $X \leftarrow Y \to Z$, and $X \leftarrow Y \leftarrow Z$) share the exact same conditional independencies and are observationally indistinguishable.

### 5.2 Contrastive Graph Discrepancy (CGD) Acquisition
To break Markov Equivalence, the agent draws $K$ candidate DAGs from its variational posterior:
$$G^{(1)}, G^{(2)}, \dots, G^{(K)} \sim q_\psi(G)$$

For a candidate intervention $a = \text{do}(X_i = v)$, the expected outcomes under the candidate DAGs diverge:
$$\hat{X}^{(k)} = \mathcal{M}_{\text{causal}}(X, a; G^{(k)}, \phi)$$

The agent selects the intervention that maximizes the **Contrastive Graph Discrepancy (CGD)**:

$$a^* = \arg\max_a \frac{1}{K} \sum_{k=1}^K \left\| \hat{X}^{(k)} - \bar{X} \right\|^2, \quad \bar{X} = \frac{1}{K} \sum_{j=1}^K \hat{X}^{(j)}$$

**Significance**:
Under passive observation, all models in the same Markov Equivalence Class predict identical distributions ($\text{CGD} = 0$). Under active intervention on the collider/mediator, the predictions diverge maximally, compelling the agent to execute the exact experiment that breaks the causal ambiguity.
